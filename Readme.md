# SQTP 项目概要

## 项目目标

面向浙大人工智能学院 **2026级人工智能专业学生**，开发一组轻量化网页工具，帮助学生自查学分、规划选课和估算成绩。项目采用“调研—开发—服务—反馈”模式，兼顾技术实践和校园公益服务。

## 服务范围与数据

- 首期仅服务人工智能专业2026级学生。
- 培养方案和课程数据依据官方资料整理，覆盖人工智能专业课程与通识必修课；暂不纳入通识选修课。
- 课程信息由团队手动整理，学生通过网页表单维护个人课程记录；首期不从教务网自动抓取。Celechron 可作为相关功能的参考。
- 学生状态分为“已修、在修、计划修读”，供学分自查、选课规划和绩点计算共享使用。
- 使用浙大统一身份认证登录，认证提供的专业和年级信息用于关联相应培养方案。网站不收集统一身份认证密码。
- 个人课程数据存储在网站账号数据库，支持跨浏览器、跨设备查询；数据传输和存储需加密。

## 四个主要页面

| 页面 | 主要功能 |
|---|---|
| **课程** | 查询专业相关课程和开课信息；进行选课模拟；查看已修、在修和计划修读进度；导出 PDF 概要，包含历史 GPA |
| **培养方案** | 查询适用的培养方案、课程要求和学分要求；展示方案适用年级和版本 |
| **绩点** | 按任课教师公布的考核比例和已知分数估算课程总评及常规课程绩点；通过逐门课程记录计算学期及累计历史 GPA |
| **我的** | 账号管理、个人课程信息编辑、内测反馈入口 |

## 重点功能实现方式

- **学分自查**：将培养方案整理为课程和学分要求，匹配学生的课程记录并显示完成进度。专业选修课程池按培养方案规定的课程范围和最低学分要求配置。
- **选课模拟**：将课程目录与每学期实际开课班次分开维护；根据先修要求、课程时间、周次和学分负担检查计划。模拟结果供规划参考，不代表教务系统中的选课结果。
- **绩点估算**：学生录入教师公布的考核项、占比、当前成绩和未出分项的预期分数；提供保守、目标、乐观三种情景，并计算估算总评和绩点。
- **历史 GPA**：学生逐门录入课程号、学分、学期、成绩等信息，由系统计算学期和累计结果。首期只使用浙大本科成绩办法中的**常规课程绩点口径**，不纳入出国成绩单 GPA。[浙江大学本科课程成绩评定与管理办法](https://meetc.zju.edu.cn/2024/0306/c79045a2885825/page.htm)
- **PDF 导出**：课程页导出的概要包含课程进度和历史 GPA；结果标明规则来源，并注明仅供参考。

## 调研、内测与成果

- 前期通过访谈和问卷了解学生的学业规划痛点。
- 计划招募 **100名人工智能专业学生**进行内测；每位用户需体验全部功能、填写问卷并报告问题。
- 根据反馈整理问题清单，持续迭代工具。
- 预期成果包括在线网页工具集群、开发文档、演示视频、痛点调研报告和用户反馈复盘材料。

## 后续需落实

- 整理并核对2026级培养方案、课程库、选修组规则及各学期开课班次数据。
- 由学院或指导老师协助确认并申请统一身份认证接入。
- 明确个人数据的保存期限、删除方式和管理权限。
