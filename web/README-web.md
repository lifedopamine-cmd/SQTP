# SQTP 网页原型

## 启动

从 `SQTP/web` 目录启动任意静态 HTTP 服务，例如：

```sh
python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。

## 当前实现范围

- 四个主页面：课程、培养方案、绩点、我的。
- 左侧桌面导航和移动端底部导航。
- 课程搜索、状态进度、培养方案多板块展开、课程详情页。
- 选课模拟的课表、先修提示、冲突检查和计划学分汇总。
- 当前课程的评分比例编辑、已知/预期分数录入、三种估分情景和常规课程绩点换算。
- 历史成绩页按学年展示示例课程、学期 GPA 和学年 GPA。
- 课程记录编辑、反馈表单、课程进度与历史 GPA 的打印/PDF入口。

## 演示数据和限制

这是纯前端原型，演示课程和历史成绩来自 `app.js` 内的样例数据。课程改动保存在当前浏览器的 `localStorage` 中。统一身份认证、云端数据库、教务网抓取和真实内测问卷均未接入；界面会标记相关内容为演示数据。

## C++ GPA 核心

`gpa_core.cpp` 实现常规课程绩点换算、按比例估算总评和学分加权 GPA，并提供 C ABI。当前页面使用 `app.js` 中的等价 JavaScript 逻辑，因为开发环境没有 Emscripten/WebAssembly 链接器。可用本机 C++ 编译器构建命令行示例：

```sh
clang++ -std=c++17 -DSQTP_GPA_STANDALONE gpa_core.cpp -o gpa_demo
./gpa_demo
```

后续如安装 Emscripten，可将 C++ 核心编译为 WebAssembly，再由页面加载；当前静态页面不依赖编译产物。
